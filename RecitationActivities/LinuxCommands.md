# More Linux Utilities
In the lecture we learned about the difference between bash and linux utils.

Activity: 
Each student takes 20 minutes to prepare a 5 minute presentation about a particular linux util.
Prep some interesting example and tell about the flags.
Ask chat gpt and look at the man page.

Utilities:
* find
* grep
* sed
* tar
* ln
* curl
* du/df
* man
* cut
* sort
* env
* export
* diff
* more
* less
