\section{Install programs}

In this assignment you'll be using the \bashcommand{tree} and \bashcommand{xxd} programs. Install them like:

\begin{lstlisting}[style=term]
root@droplet$ apt install tree xxd
\end{lstlisting}

\begin{itemize}
\item \bashcommand{tree} - lets you see your directory structure as a nice graphical tree.
\item \bashcommand{xxd} - gives a hex dump of a file so you can see the file in hexadecimal. This is an important command you'll use when inspecting files. We present it in this docuument, which is likely your first exposure to the xxd command. 
\end{itemize}

\subsection{users}
Linux is a multi-user operating system. Our droplets by default only come with one user - root - but you can add more users to your computer. 

\subsection{adduser}
To add a user, you use the \bashcommand{adduser} command. When you add a user you'll be prommpted to give a password. After providing the password, you're asked a bunch of questions. You can just hit ENTER repeatedly and not enter values for things like Room Number.

See figure \ref{fig:adduser}. Note that in the beginning there are only directories for jack and jill. When I add the user bruno and \bashcommand{ls /home}, you see that there is now a home directory for bruno. When you run \bashcommand{adduser}, a home directory is added for the user.

\subsection{Permissions}
Linux files and directories have permissions. Files can directories can be:

\begin{itemize}
\item readable
\item writable
\item executable
\end{itemize}

These permissions are specified in three ways:

\begin{itemize}
\item owner
\item group
\item everyone else
\end{itemize}

So files and directories have 9 permission fields. They have readable, writable and executable for each of owner, group and everyone else. See figures \ref{fig:permission001} and \ref{fig:permission002} to see two examples of permissions. Permissions are show with 9 characters.

\myfig{Images/permissions001.png}{See the circled area. 9 characters indicate read, write an execute for each of owner, group, and everyone else}{fig:permissions001}

\myfig{Images/permissions002.png}{The red circle indicates permissions for owner. Blue indicates group. Green indicates everyone else}{fig:permissions002}
