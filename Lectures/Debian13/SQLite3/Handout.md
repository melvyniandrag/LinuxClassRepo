# SQLite3

Databases can be thought of as very fancy Excel spreadsheets that you can interact with using a
programming language called SQL. There are many "dialects" of SQL, depending on the database you
use, but they all work essentially in the same way. Each flavor of SQL / Database you use will have
some special feature that makes it stand out, but the general idea is always the same. Databases
store data, and you insert, retrieve, update and delete this data using a language called *SQL*.

Databases are very important for many practical things you will do on Linux. There are many popular
databases such as
1. PostgreSQL
1. mySQL
1. Microsoft Access
 
 but I would wager that the most widely used database is SQLite3! SQLite is a powerful, lightweight
 and super easy to use! I told you that databases are important to Linux, but thats not the whole
 picture... If you work in software - mobile apps, web development, embedded software -
 you're almost certain to use a database, and quite often that db will be sqlite!


 ## What is a database?
 A database is a place to store data. Sometimes the database is a complex thing that runs on a
 server , in the case of PostgreSQL or mySQL. But sqlite is special! sqlite stores the database in a
 small file and you can interact with it easily, as  you'll see in today's lesson.

 ## What is SQL?
 SQL is the language you use to Create, Retrieve, Update or Delete data from a database. *tell
